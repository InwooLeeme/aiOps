연속 14일의 관측값으로 입력 마지막 날짜 다음 날의 총발전량을 예측합니다. 일자별 값은 해당 날짜가 끝난 뒤 사용합니다. 운영 예측은 KST 00:00~00:59에 직전 날짜까지의 데이터로 발행하며, 그 밖의 요청은 과거 점검으로 분류합니다. 현재 시각 기준 예측이 아닐 수 있습니다. 과거 데이터 점검은 운영 성능에서 제외합니다.

시연 제어 · 성능 저하와 자동 재학습
정상 배치는 원본 관측값을, 드리프트 배치는 격일로 일별 총발전량을 10%로 제한한 합성 데이터를 사용합니다. 감지 → 자동 재학습 → 검증 → 승격을 한 번에 실행합니다.
원본 CSV는 보존합니다. 검증을 통과하면 JejuSolarDailyPredictor 운영 모델이 교체됩니다. 통과하지 못하면 기존 모델을 유지합니다. 승격 후에는 새 모델의 학습·검증 종료 이후 구간을 선택하세요.

데이터 업로드
일별 집계 CSV 또는 시간별 원본 CSV(자동 일별 집계)를 업로드합니다. 발전량은 MWh, 설비용량은 MW입니다. 업로드 시 저장된 예측에 실제 발전량을 연결합니다. 운영 평가에는 예측 발행 후 도착한 관측값을 사용합니다. 1건 예측에는 연속 14일의 관측값이 필요합니다.

        

      

      
참조 데이터
한국동서발전이 제공한 제주 시간별 태양광 발전량 및 기상 데이터를 사용합니다. 시간별 발전량은 날짜별로 합산하고 기상·설비용량은 평균을 사용합니다. 24시간이 모두 유효한 변수만 사용하며, 결측일을 가로지르는 입력은 제외합니다.
