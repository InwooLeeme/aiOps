데이터 업로드
날짜·종가·거래량 컬럼을 가진 UTF-8 CSV를 업로드합니다. 최소 41행이 필요하며, 다음 학습부터 최신 파일을 사용합니다.

        

      

      
참조 데이터
제공된 HAIC 샘플은 종가와 거래량을 포함하는 756행의 실습용 시세입니다. 업로드 데이터가 없을 때 화면과 예측 입력의 예제로 사용합니다. 모델 학습 전에 CSV를 업로드하세요.
