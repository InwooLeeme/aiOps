Day1 — 다음 1시간 태양광 발전량 예측

최근 72시간의 제주 발전량·설비용량·기상 관측값으로 다음 1시간 발전량(MWh)을 예측합니다. 입력 시각은 한국 표준시(KST)이며 미래 기상 관측값은 사용하지 않습니다.


      

      

        
Day3 — 드리프트 시뮬레이션 · 자동 재학습
정상 배치는 원본 관측값을, 드리프트 배치는 08~18시 짝수 시간의 발전량을 10%로 제한한 합성 데이터를 사용합니다. 감지 → 자동 재학습 → 검증 → 승격을 한 번에 실행합니다.
원본 CSV는 보존합니다. 검증을 통과하면 JejuSolarPredictor 운영 모델이 교체됩니다. 통과하지 못하면 기존 모델을 유지합니다. 승격 후에는 새 모델의 학습·검증 종료 이후 구간을 선택하세요.

        
연속 168시간 평가 · 기본 구간은 제주 데이터용 시연 구간입니다.

        

        
정상 배치로 비교한 다음 드리프트 배치를 전송하세요.

        

        
시뮬레이션 상세 결과

      

      

        
실제 과거 구간 리플레이
업로드한 제주 데이터의 예측 대상 시각부터 순서대로 모델 성능을 평가합니다. 학습·검증 이후 구간(기본 2024년부터)을 선택하세요. 누락 구간은 제외하고 최근 168시간의 RMSE를 검증 데이터에서 정한 임계값과 비교합니다.

        

        

        

      

      

        
시간 경계를 지정한 재학습
최근 리플레이의 마지막 평가 시각까지 모델을 학습·검증합니다. 종료 시각은 평가 결과로 자동 입력되며, 이후 구간은 평가용으로 남겨둡니다.

제주 태양광 데이터셋
최신 업로드 데이터의 통계를 불러오는 중입니다.

        

      

      

        
데이터 업로드
공공데이터 원본 한글 컬럼(CP949) 또는 정규화한 UTF-8 CSV를 업로드합니다. 발전량은 MWh, 설비용량은 MW입니다. 1건 예측에는 연속 72시간의 관측값이 필요합니다.

        

      

      
참조 데이터
한국동서발전이 제공한 제주 시간별 태양광 발전량 및 기상 데이터를 사용합니다. 제주 지역의 시간별 발전량 합계를 예측하며, 야간 발전량 0은 실제 관측값으로 유지합니다. 누락된 시간은 임의로 채우지 않습니다.
